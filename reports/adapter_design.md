## 1. Architecture Overview

Each dataset gets its own **Adapter class** that:
1. Loads raw data from disk (GDSII/SPICE/JSON → structured dict)
2. Applies feature selection (include/exclude rules below)
3. Returns a normalized pandas DataFrame ready for ML pipelines


## 2. OSIRIS Adapter Design

### 2.1 Features to INCLUDE

#### Group A: Circuit Topology (Categorical)
| Column | Type | Rationale |
|---|---|---|
| `topology` | str (encoded) | Defines the circuit architecture class |
| `circuit_id` | str | Sample identifier (not a feature — use as index) |
| `netlist_id` | str | Links back to schematic template |

#### Group B: Transistor Sizing (Continuous — PRE-layout)
| Column | Type | Rationale |
|---|---|---|
| `transistor_width_W` | float (μm) | Primary sizing parameter |
| `transistor_length_L` | float (μm) | Primary sizing parameter |
| `finger_count` | int | Number of parallel gate fingers |
| `multiplicity` | int | Device multiplier (m parameter) |
| `finger_arrangement` | int/categorical | How fingers are split across the layout |

#### Group C: Placement / Layout Geometry (Continuous — PRE-verification)
| Column | Type | Rationale |
|---|---|---|
| `x_position` | float (μm) | Device placement x-coordinate |
| `y_position` | float (μm) | Device placement y-coordinate |
| `orientation` | int (0/90/180/270) | Device rotation (encoded as int) |
| `perturbation_id` | int | Which perturbation variant this is |
| `delta_x` | float (μm) | X-offset from baseline placement |
| `delta_y` | float (μm) | Y-offset from baseline placement |

#### Group D: Verification Flags (Boolean — POST-layout)
| Column | Type | Rationale |
|---|---|---|
| `drc_clean` | bool | Use as class filter (exclude failed) or classification target |
| `lvs_verified` | bool | Use as class filter (exclude failed) or classification target |

---

### 2.2 Features to EXCLUDE

#### ❌ Post-verification-only Columns (Target Leakage Risk)
If used as inputs when predicting QoS metrics, these constitute **data leakage** because they are only available after the full simulation loop completes — the same loop that produces the QoS targets.

| Column | Reason for Exclusion |
|---|---|
| `parasitic_capacitance` | Only available post-PEX; leaks into QoS prediction |
| `parasitic_resistance` | Only available post-PEX; leaks into QoS prediction |
| `rc_network_id` | References post-PEX extracted netlist |
| All QoS metrics (when used as inputs) | These ARE the targets; using them as inputs = leakage |

#### ❌ Administrative / ID Columns (Non-predictive)
| Column | Reason for Exclusion |
|---|---|
| `circuit_id` | Use as DataFrame index, not feature |
| `netlist_id` | Identifier, not a generalizable feature |
| `template_id` | High cardinality ID with no ordinal meaning |

### 2.5 Preprocessing Recommendations

| Step | Action |
|---|---|
| **Filter** | Keep only `drc_clean=True AND lvs_verified=True` rows for QoS prediction tasks |
| **Encode topology** | One-hot encode circuit topology (expected few categories) |
| **Encode orientation** | Map {0, 90, 180, 270} → {0, 1, 2, 3} ordinal or one-hot |
| **Scale numerics** | StandardScaler for regression; MinMaxScaler acceptable for tree models |
| **Multi-output** | Wrap in `sklearn.multioutput.MultiOutputRegressor` or native XGBoost multi-output |
| **Outlier removal** | Clip QoS targets at 1st/99th percentile to handle simulation artifacts |

## 4. Unified Adapter Interface

Both adapters should expose a common interface so the ML pipeline can work with either dataset interchangeably:

```python
from abc import ABC, abstractmethod
import pandas as pd

class BaseAnalogDatasetAdapter(ABC):
    """Common interface for all analog IC layout dataset adapters."""
    
    DATASET_NAME: str = ""
    DATASET_VERSION: str = ""
    LICENSE: str = ""
    DOWNLOAD_URL: str = ""
    
    @abstractmethod
    def load(self, data_dir: str) -> None:
        """Load dataset from local directory into memory."""
    
    @abstractmethod
    def get_features(self, groups: list[str] | None = None) -> pd.DataFrame:
        """Return feature matrix. Optionally filter by feature group names."""
    
    @abstractmethod
    def get_targets(self, targets: list[str] | None = None) -> pd.DataFrame:
        """Return target matrix. Optionally select specific targets."""
    
    @abstractmethod
    def get_safe_pretrain_features(self) -> pd.DataFrame:
        """Return only PRE-layout features safe from post-verification leakage."""
    
    def get_ml_ready(
        self,
        feature_groups: list[str] | None = None,
        targets: list[str] | None = None,
        pre_layout_only: bool = True,
    ) -> tuple[pd.DataFrame, pd.DataFrame]:
        """Return (X, y) tuple ready for ML training."""
        X = self.get_safe_pretrain_features() if pre_layout_only else self.get_features(feature_groups)
        y = self.get_targets(targets)
        return X, y
```

## 5. Feature Leakage Risk Matrix

| Feature Category | Use as Input? | Risk Level | Notes |
|---|---|---|---|
| Netlist topology (W, L, fingers) | ✅ Yes | 🟢 None | Available pre-layout |
| Placement coordinates | ✅ Yes | 🟢 None | Available after placement, pre-simulation |
| DRC status | ⚠️ Conditional | 🟡 Low | Use as filter or target, not input to QoS model |
| LVS status | ⚠️ Conditional | 🟡 Low | Use as filter or target, not input to QoS model |
| Extracted parasitics (R, C) | ❌ No (for QoS) | 🔴 HIGH | Only available post-PEX — same step that enables QoS sim |
| QoS metrics (gain, GBW, etc.) | ❌ No (as inputs) | 🔴 CRITICAL | These ARE the targets |
| Pre-layout ideal simulation values | ✅ Yes (if available) | 🟢 None | Available before layout; useful for degradation prediction |
